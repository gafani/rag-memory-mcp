# Task Completion Checklist

When a task is completed, ensure the following:

1. **Verify**: Check if the code compiles (`npm run build`).
2. **Test**: Run relevant tests or manual verification scripts.
3. **Format**: Ensure code follows project style (though no specific linter script is currently defined, follow standard TS conventions).
4. **Document**: Update README or comments if necessary.
5. **Clean**: Remove any temporary files created during testing.
