# Project Overview: rag-for-agent-mcp

## Purpose
A RAG (Vector + Reranking) memory server designed for Agents, utilizing LanceDB for vector storage and Google Gemini for embedding and reranking.

## Core Features
- Vector Search with LanceDB
- Reranking with Google Gemini
- Web Dashboard for visualization
- MCP Protocol support

## Tech Stack
- **Runtime**: Node.js (v24.12.0 recommended)
- **Language**: TypeScript (ESM)
- **Framework**: Hono (Web Server), Model Context Protocol (SDK)
- **Database**: LanceDB
- **AI**: Google Generative AI (Gemini)
