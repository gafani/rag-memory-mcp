# Suggested Commands

## Build & Run
- `npm install`: Install dependencies
- `npm run build`: Compile TypeScript to JavaScript
- `npm start`: Run the server (from `dist/index.js`)

## Development & Testing
- `npm run view`: Launch the web dashboard (or `npx tsx src/dashboard.ts`)
- `npx tsx src/scripts/test-manual.ts`: Run manual tests (requires .env)

## System
- `ls -F`: List files
- `git status`: Check git status
